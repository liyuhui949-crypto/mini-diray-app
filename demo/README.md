# 演示数据：近 40 天日记

`40-days.minidiary` 是一个真实的迁移包（2026-09-28 → 2026-11-06，32 篇日记、10 个附件、约 54 MB），
由 `node scripts/seed-demo.mjs` 在隔离环境里用应用自己的 IPC 写入并导出，格式与手动写作完全一致。

导入需要**公钥 + 私钥**两样东西（公钥由脚本生成，只保存在本机）：

| | 值 | 位置 |
|---|---|---|
| 公钥 | 见 `demo/40-days.key.txt` 第一行 | 就是下面这条 |
| 私钥 | `demo-123456` | 包密码 |

`40-days.key.txt` 每次重新生成包都会变，公钥丢了包就作废。

## 怎么导入

1. 打开 Mini Diary。已有日记库就直接解锁；没有的话点引导页的「导入迁移包」。
2. 设置 → 数据 → 一键迁移 → **导入…**（或引导页/菜单里的入口），选 `demo/40-days.minidiary`。
3. 输入**公钥**（粘贴 `demo/40-days.key.txt` 里那串，可带或不带短横线）和**私钥**：`demo-123456`
4. 选择导入方式：
   - **替换当前日记库**：清空现有内容（包括你自己的测试条目），得到一份干净的演示库；
   - **合并到当前日记库**：保留现有条目，把 32 篇演示数据加进去（同一天会按规则拼接，不会覆盖）。
5. 不需要设置新密码：已经解锁的库沿用原密码；全新安装时，导入后用迁移包的私钥（包密码）解锁。
6. 完成后直接进入三栏界面。

> 导入不会删除任何旧文件：切换前会把原库保留为临时回滚点，校验通过后才删除。

## 建议的测试路径

- **日历**：10 月有 25 篇，带圆点的日期成片；点空档日期（如 10-17）应显示「这一天还没有字」。
- **列表与搜索**：搜「专注」命中 10-04、10-05、11-05、11-06；搜「老陈」命中 10-01、10-08、10-26；
  点标签 `#工作` 只看工作类条目。
- **编辑器**：打开 11-06（markdown 里有 `> 引用` 与 `**加粗**`），切到「预览」看渲染；
  打开 10-16 看标题/列表/行内代码；11-04 的 ZIP 附件可以「另存为」。
- **媒体**：10-19 播放 `楼下的花.mp4` 并拖动进度；11-03 播放 90 秒雨声并 seek；10-26 是 webm。
- **图片**：10-04、10-12、10-24 各有一张，点图可放大，预览里点图进 lightbox。
- **统计**：总条目 32、每周平均 5.3、最长连续 7 天、当前连续 4 天、总字数约 2474。
- **清理未引用附件**：设置 → 数据 → 清理未引用附件，应能找到 1 个（`截图-未引用.png`）并提示先导出迁移包。
- **锁定**：`⌘L` / 侧栏「锁定」，内容立即消失；重新解锁后媒体仍可播放。
- **迁移**：设置 → 导出迁移包，勾一份带附件的包，再导入回来验证轮转；也能验证 54 MB 的导入耗时。
- **偏好**：切换深色/浅色、隐藏标题（列表改用正文首行）、允许写未来日期、空闲自动锁定。

## 重新生成

```bash
pnpm build                       # 脚本用的是构建产物
node scripts/seed-demo.mjs       # 覆盖 demo/40-days.minidiary 与 demo/40-days.key.txt（公钥会变）
node scripts/seed-demo.mjs --big # 额外生成 320 MB 归档，用来测试 >300 MB 的二次确认
```

脚本不会碰你的真实日记库：它在临时目录里启动 Electron，写入数据、导出迁移包，然后清理临时目录
（`MINIDIARY_USER_DATA` / `MINIDIARY_DIARY_DIR` 两个只在测试/开发用的环境变量负责隔离）。

附件大小：默认 54 MB；`--big` 约 374 MB。演示视频来自 MDN 的 CC0 示例素材，仅用于本地测试。
