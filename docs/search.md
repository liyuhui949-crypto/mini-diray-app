# 检索功能

Mini Diary 的检索在本机完成，不依赖服务器，也不会把搜索词发到网络。

## 检索方式

- 搜索标题、正文和标签；
- Markdown 会被转成纯文本后匹配；
- 支持中文子串；
- 空格分隔多个词时使用 **AND**：每个词都要命中；
- 全角/半角、大小写通过 Unicode NFKC + 小写归一化；
- 输入停手 320ms 自动检索，按回车立即检索。

## 结果与洞察

一次检索会同时得到：

- 命中篇数；
- 最早、最近命中日期；
- 逐月时间线；
- 按年份分组的命中证据；
- 每篇的标题命中次数、正文命中次数；
- 命中位置附近的摘要片段；
- 连续命中日期段。

时间线跨度超过 30 个月时，自动从“按月”切换为“按年”。

## 列表与预览

- 列表默认跟随日历月份，可切到「全部」跨月浏览；
- 标签筛选与搜索始终围绕全库；
- 检索结果可以打开预览，不打断当前检索；
- 预览里可以跳到对应日记。

## 标题隐藏

隐藏标题只影响显示。正文首行可以作为列表标题，但搜索仍然会匹配原始标题字段。

## 实现方式

检索没有数据库索引，直接在当前已加载的条目上扫描：

```text
normalize(query)
→ 分词
→ 每条日记匹配标题 / 纯文本正文 / 标签
→ 汇总命中、摘要、时间线和连续段
```

因此：

- 搜索是本地内存计算，不会触发同步；
- 结果随本地条目实时变化；
- 大数据量时仍是一次线性扫描，但不需要维护额外索引；
- 检索不修改日记内容。
