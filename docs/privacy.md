# 隐私与安全

## 默认本地

Mini Diary 没有账号系统，也没有云端服务。默认情况下：

- 日记保存在本机；
- 不向服务器上传内容；
- 没有遥测或广告；
- 不要求登录。

## 加密

- 日记库使用随机 DEK 加密。
- 密码只用于包裹 DEK，修改密码不需要重新加密全部内容。
- 正文、批注和附件分别使用派生密钥加密。
- 锁定后清除内存中的密钥。

## Git 同步

Git 同步是可选功能，默认关闭。

开启后，仓库中只有：

- 加密后的正文；
- 加密后的批注；
- 同步元数据。

不会进入 Git：

- 今天的正文和批注；
- 附件文件；
- 密码、DEK；
- Git token；
- 代理设置。

GitHub 上能看到哪些日期有记录，但看不到正文内容。

## 备份与恢复

Git 仓库不是可以直接恢复的备份。清空本地数据或换电脑后，需要：

- `.minidiary` 完整迁移包；或
- `.inkkey` 恢复密钥 + Git 仓库。

没有恢复密钥，仓库里的旧密文无法解密。

## 密码

密码不会上传，也无法找回。忘记密码后，已加密内容不能恢复；请务必保存好密码和恢复密钥。

## 系统权限

macOS 上可能用到：

- **文稿文件夹**：保存加密日记和附件；
- **本地网络**：仅在使用本地 Git 代理时请求。

不需要相机、麦克风、屏幕录制、辅助功能或完全磁盘访问权限。
