# 功能

## 写作

- 一天一篇，标题 + Markdown 正文。
- 加粗、斜体、列表、引用工具栏。
- 实时字数、800ms 自动保存。
- 失焦、切换日期、锁定和退出前自动保存。
- 预览和源码模式切换。

## 日历与整理

- 月历视图，有内容的日期显示圆点。
- 未来日期限制，随时回到今天。
- 标签整理，跨月份浏览全部条目。
- 全库中文子串搜索，多词同时匹配。

## 批注

- 与正文平行的第二条记录流。
- 选中一句话添加批注，可从批注跳回原文。
- 历史正文只读，批注只增不改。
- 批注和正文使用同一把日记库密钥加密。

## 附件

- 图片、音频、视频和其他文件。
- 写入磁盘前按块加密，磁盘上不会出现明文附件。
- 图片灯箱、音视频播放、拖动进度。
- 附件库按类型聚合；可查看未引用附件并清理。

## 检索与统计

- 检索洞察：命中篇数、时间范围、逐月时间线。
- 按年份分组的命中证据。
- 总条目、连续记录、总字数、周/月趋势和热力图。
- 存储占用统计。

## 迁移与备份

- `.minidiary` 整库迁移包：正文、批注、附件和设置。
- 公钥 + 私钥双因子保护。
- 支持整库替换和合并导入。
- `.inkatt` 附件包用于单独补齐附件。
- `.inkkey` 恢复密钥用于清空或换电脑后重新解密 Git 仓库。

## 可选 Git 同步

- 默认关闭，需要手动开启。
- 使用系统 Git，只同步加密后的正文和批注。
- 今天的内容不同步，第二天才会进入同步范围。
- 附件不进入 Git。
- 仓库里只有密文；GitHub 上看不到日记内容。
- 令牌用日记库密钥加密保存，不写入仓库。
