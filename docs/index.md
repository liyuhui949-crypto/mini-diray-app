# Mini Diary

本地优先、默认加密、离线可用的桌面日记。

没有账号，不依赖云服务；正文、批注和附件都在这台电脑上加密保存。

[看看功能]({{ '/features/' | relative_url }}) · [开始使用]({{ '/usage/' | relative_url }}) · [隐私与安全]({{ '/privacy/' | relative_url }})

## 它是什么

Mini Diary 是一个面向个人长期记录的桌面日记应用。它把「写下来」放在第一位：一天一篇、Markdown 正文、标签、搜索、批注、附件和统计都在同一个本地应用里完成。

它不要求注册账号，也不会把日记上传到服务器。默认情况下，所有内容只存在你的电脑上，并由你的密码保护。

## 主要特点

- **本地优先**：默认不联网，没有账号体系。
- **加密存储**：正文、批注、附件在落盘前加密。
- **一天一篇**：日历、标签和全文检索围绕日常记录设计。
- **历史批注**：历史正文只读，随时可以在原句旁补批注。
- **附件加密**：图片、音频、视频和其他文件流式加密保存。
- **可迁移**：`.minidiary` 整库备份，换电脑不需要重新整理。
- **可选 Git 同步**：只同步正文和批注的密文，不同步附件和今天的内容。

## 适合谁

适合希望把日记留在自己电脑上、又不想牺牲搜索和整理体验的人。
