# 使用说明

## 第一次打开

1. 启动应用 → 设置密码（至少 8 位，两次输入一致）→ 创建日记库。
2. 已有其他电脑的迁移包？点引导页底部"导入迁移包"，选文件、输包密码、设置新密码即可。

数据默认放在 `~/Documents/Mini Diary`（macOS），可在「同步 → 数据」里整体迁移到别的目录：

```text
<日记目录>/
├─ diary.vault        # 加密的整库（标题、正文、标签、附件引用、字数、时间戳）
└─ attachments/       # 每个附件一个 <uuid>.mdat 密文文件
```

## 写作

- 选中日期就能写；`⌘N` / `Ctrl+N` 回到今天。
- 正文是 Markdown 源码：`**加粗**`、`*斜体*`、`- 列表`、`1. 列表`、`> 引用`。
  工具栏四个按钮分别对应这四种格式，快捷键 `⌘B` / `⌘I` / `⌘⇧8` / `⌘⇧7`。
- 停手 800ms 自动保存；失焦、切日期、锁定、退出前都会先 flush。
- "预览"按钮把 Markdown 渲染出来（图片、音频、视频用原生控件），"源码"切回编辑。
  这个选择会跨日记保留：开着预览去翻别的日期，内容也以预览显示（重启应用后回到源码模式）。
- 标题可以在设置里隐藏（数据保留，列表改用正文首行）。
- 标签在标题下方 `＋ 标签` 处添加，回车确认。

## 附件

- 点工具栏"附件"选文件，或直接把文件拖进编辑器，或粘贴剪贴板里的图片（≤50 MB）。
- 所有附件在写入磁盘前就按分块加密（MDAT v1），磁盘上不会出现明文文件。
- 图片在预览里内嵌显示，点击可放大；音频/视频用原生播放器，视频可以拖动进度
  （`attachment://` 解密代理支持 HTTP Range）。
- 附件大小上限：图片 50 MB / 音频 500 MB / 视频 2 GB / 其他文件 2 GB；超过 300 MB 会二次确认。
- 删除附件只删除日记里的引用，密文文件要等附件库「未引用」里执行清理时才真正释放空间。

## 附件库

侧栏「附件」把整库附件按类型摆出来，不用先想起是哪一天：

- 顶部五类 tab（全部 / 图片 / 视频 / 音频 / 文件）带实时计数，旁边是总体积与「全部 AES-256-GCM 加密存放」；
- 图片/视频/音频是图片墙（正方形卡，懒加载、滚动跳过视口外渲染），文件是不可预览的行列表；
- **点击任意卡片或行 = 打开所属日记的预览**：全文、标签、附件都在，脚注写明「来自附件库 · 这篇共 n 个附件 · 关闭即回」；
- 预览里点「在日记中打开」才真正跳走；关闭对话框会留在附件库，tab 与滚动位置都不丢；
- 新增/删除附件后重新进入即是最新结果（视图是 `entries` 的纯派生，不建索引文件）；
- 空库显示引导，可以直接「写今天的日记」；
- **点击预览方式**（右上角按钮组）：选「预览日记」时点可预览附件进所属日记预览，选「预览附件」时直接进灯箱；
  这个选择会记住；在预览里也能随时互相切换（「预览附件」/「查看所属日记」），切换本身不改变外层选择；
- **未引用 tab**：被删除或替换掉的附件会留在这里（显示推断出的类型与大小）；图片/视频/音频可以直接预览
  （孤儿附件同样走 `attachment://` 解密代理），文件类标注「不可预览」；清理入口也在这里，设置页不再有。

## 调整三栏宽度

- 只有**条目列表**可以拖边缘改宽（240–420px）；左栏和批注栏都是固定宽度；
- 左栏、批注栏只有**完全展开 / 完全收起**两态：
  - 左栏用标题栏左侧的按钮（或菜单「视图 → 折叠侧栏」，`⌘⌥B`）；
  - 批注栏用头部「›」收起，收起后正文右上角留「批注 n」药丸展开；
- 键盘也能调：`Tab` 聚焦到手柄后按 `←/→`（按住 `Shift` 每次 32px），双击手柄恢复默认宽度；
- 左栏左上角的按钮（或菜单「视图 → 折叠侧栏」，`⌘⌥B`）可整列收起；批注栏头部的「›」收起后，
  正文右上角会留一个「批注 n」药丸，点一下重新展开；
- 列表宽度范围 240–420px（默认 312px），不会自动收起；
- 列表宽度、左栏/批注栏的折叠状态都会记住，下次打开还是这个样子；
- 窗口变窄时批注栏固定 326px（写批注时 384px），不改宽度。

## 批注（历史不可改，但可以补充）

产品规则：**只有今天能写正文**。历史日期的标题、正文、附件一律只读，空的历史日期也不能补写。
批注就是唯一的补偿通道：原文一个字不动，批注单独存放、只增不改不删。

- 打开任意历史日记 → 右侧出现「批注」栏；选中正文里的一句话，会浮出「加批注」，
  点它展开批注编辑区：引文 + `#` 标签 + 正文，`⌘/Ctrl+Enter` 保存（批注栏顶部只提示「选中正文即可加批注」，不再有加号按钮）；
- 保存后正文该句带**土黄虚线下划线**（锚点），点它跳到右侧卡片；点卡片正文会滚到锚点并闪一下；
- 空的历史日期（那天没写）显示「已封存 · 不可新增正文」，可以「给这一天加批注」写**整篇批注**；
- 日历：绿点 = 有日记，红点 = 只有批注；列表行显示「批注 n」角标；
- 状态栏：历史日期显示「只读 · 批注 n 条」，空日期显示「只读 · 无正文 · 批注 n 条」；
- 今天的日记仍然可以正常写、正常自动保存，批注与编辑互不干扰；
- 批注与正文同库同密钥加密（`annotations/<日期>.ann`，每行独立 AEAD），锁定即销毁内存副本；
- 批注没有"编辑/删除"：写错了就再写一条更正——这是 append-only 的有意设计。

## 搜索、日历、统计

- 中间的条目列表默认只显示**日历当前月份**的日记，标题右边有「本月 / 全部」切换；
  翻动日历时列表跟着换月，想看跨月汇总就切到「全部」。
- 不再有「新建」按钮：要写今天就点左侧「回到今天」（或日历上的今天），
  空白日期会显示「开始写」。
- 搜索框里打字后**停手 0.3 秒自动检索**，也可以按回车 / 点右侧的检索按钮立即检索；输入期间列表不动，
  避免每敲一个键就全量分析。多个词用空格分隔是"与"关系；搜索始终是全库范围，点标签也是跨月视图。
  搜索框里只有检索按钮，没有清空按钮——按 Esc 或删掉内容即可退出检索。
- 检索结果会在右侧变成**检索洞察**，自上而下三层：
  1. **概览**：命中篇数 + 最早—最近命中日期；副行按年份列出「yyyy-mm-dd 几篇命中」，
     例如「跨 2 个年份 · 2026-01-01 9 篇命中；2025-11-02 3 篇命中」；
  2. **时间线**：从最早命中月到最近月的逐月柱状，**每根柱子头顶标自己的命中篇数**（不按最高柱统一对齐），
     下方标 `yyyy-mm` 月份；空月份保留矮柱（能看出停更期），跨度超过 30 个月自动按年聚合；
     点某一根柱：左侧日历切到那个月、证据列表滚到该月并把它"仿高亮"（其余月份淡出），再点一次取消；
  3. **证据列表**：按年份分组，**不同年份用不同的浅色块**（组头与行底色同色系，柱子也跟着年份上色），
     每条显示日期、标题与最多两条上下文片段。
- 点证据行、或中间列表里的搜索结果，都会打开同一个**预览对话框**（全文渲染 + 命中词高亮），
  不会直接跳走；关掉就回到原来的检索结果，不会丢状态。
  对话框里的「在日记中打开」才真正跳到那天，编辑器里命中词带底色、
  状态栏显示「命中 n 处」，一开始输入就自动清除。
- 日历上有圆点的日期有日记；方向键 / PageUp / PageDown / Home / End 可以移动选择；
  "跳转日期"可以直接输入某天。
- 统计页给出六项指标（总条目、每周平均、最长连续、当前连续、总字数、每篇平均）、
  近 12 周柱状图、13 周热力图和存储占用。

## 一键迁移（换电脑 / 归档）

旧电脑：

1. 同步 → 数据 → 一键迁移 → **导出…**
2. 输入**私钥**（自定义密码，可以和日记密码不同）→ 点「生成公钥」。
3. 复制并单独保存**公钥**（128 位、区分大小写，形如 `8NRS-F9AZ-…`）。应用不会保存它，
   丢了这个包就永远打不开；5 秒倒计时结束后才能开始导出。
4. 得到的 `Mini Diary 迁移包 YYYY-MM-DD.minidiary` 就是整库副本：
   全部条目、标签、附件（含未被引用的）、可移植偏好（主题、隐藏标题等）都在里面。

> **公钥和迁移包请分开存放**（比如公钥抄在纸上、包放硬盘）。两者放在一起就等于没有这道防线。

新电脑：

1. 安装应用 → 引导页点"导入迁移包"（已解锁的话在设置里点"导入…"）。
2. 选包 → 输入**公钥**（导出时保存的那串字符，可带或不带短横线，区分大小写）和**私钥**（包密码）→ 预览摘要 →
   选 replace（替换）或 merge（按日期合并）。旧版本导出的包（不带公钥的格式）已不再支持导入。
3. **不需要设置新密码**：已经解锁的库导入后继续用原来的密码；全新安装（没有库）导入后，
   用迁移包的私钥解锁。
4. 导入过程先写临时 staging，校验通过后才原子切换；中途失败会恢复原库。

要点：

- 所有密码输入框右侧都有「显示/隐藏密码」按钮（解锁、建库、修改密码、清空全部数据、导出/导入私钥），
  可以确认自己输的内容再提交。
- **公钥 + 私钥缺一不可，两者都没有找回手段。** 只丢公钥或只忘私钥，包都解不开。
- 迁移包是唯一的完整副本：没有自动备份、没有历史版本。重要节点请主动导出一份。
- 「清空所有数据」会删除本机的全部日记、批注、附件、密码和配置，恢复到刚安装的状态，不可恢复、没有回收站；
  执行前界面会提示先导出迁移包，并要求输入密码 + 确认短语「我确定清空全部数据」。
- 双击 `.minidiary` 文件可以直接打开导入向导。

## 导入导出（外部格式）

- 支持导入：Day One JSON、jrnl JSON、Mini Diary JSON、Day One TXT（只导入文本，附件不参与）。
- 支持导出：Mini Diary JSON、Markdown（可选同时复制附件）、PDF、Day One TXT。
- 同一天的内容不会被覆盖：标题拼成 `旧 | 新`，正文之间插入 `---`，标签取并集。
- 导出的文件是**明文**，界面会明确提示；需要加密完整备份请用迁移包。
- PDF 使用内嵌的 Noto Sans SC，中文不会乱码；音频/视频在 PDF 里显示为附件卡片。

## 隐私与安全

- 没有账号、没有任何网络请求（也不做在线更新，升级靠下载新安装包覆盖安装）、没有崩溃上报。
- 渲染进程没有文件系统能力；所有文件操作在主进程完成。
- 附件响应带 `Cache-Control: no-store`，不会被 Chromium 落盘缓存。
- 日志只记录技术事实（数量、字节数、错误码），不记录密码、密钥、正文或文件名。
- 锁屏 / 挂起 1.5 秒内锁定；可选的空闲自动锁定默认关闭。

## 忘记密码怎么办

没有找回。密码只在你脑子里，我们也没有后门。
如果还留着导出过的迁移包，可以重新建库再导入（需要迁移包密码）。

## 已知限制

- 视频只支持 Chromium 自带解码的格式（MP4/H.264、WebM 等），不支持 HEVC/MKV，也不做转码和缩略图。
- 不提供多语言界面。
- 不支持多个日记库、云同步、移动端。
- Windows / Linux 的安装包与签名需要各自的环境验证。
