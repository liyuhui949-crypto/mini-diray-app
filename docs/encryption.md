# 加密功能

Mini Diary 的目标是：正文、批注和附件在落盘前就完成加密，磁盘上不出现明文内容。

## 日记库信封

`diary.vault` 是一个加密信封：

```text
vaultId
scrypt 参数和 salt
用密码派生的 KEK 包裹的 DEK
用 DEK 派生的 payload key 加密的整库 JSON
```

关键点：

- 密码不会保存；
- 密码通过 scrypt 派生 KEK；
- 每次创建库生成随机 32 字节 DEK；
- 密码只负责包裹 DEK，修改密码不需要重新加密全部日记；
- 所有加密块使用 AES-256-GCM，带认证标签；
- AAD 绑定版本、`vaultId` 和用途，篡改会解密失败。

默认 scrypt 参数：

```text
N = 131072, r = 8, p = 1
```

## 子密钥

DEK 不直接用于所有内容，而是通过 HKDF-SHA256 按用途派生：

```text
payload-v1          日记库主体
attachment-v1       附件
annotation-v1       批注
sync-v1             Git 镜像条目
sync-token-v1       Git token
inkatt-manifest-v1  附件包清单
```

不同用途不复用同一把子密钥。

## 附件

附件使用 MDAT v1 分块容器：

- 64 字节头；
- 1 MiB 默认分块；
- 每个分块独立 AES-256-GCM；
- nonce 由文件前缀和块号组成；
- AAD 绑定文件头、块号和明文长度；
- 文件头有 HMAC 校验；
- 支持流式写入、随机读取和视频 Range 请求。

因此大视频不需要整体读入内存，也不需要解密后才能 seek。

## 批注

批注文件按日期保存，每行一条独立密文：

- 使用 `annotation-v1` 子密钥；
- 每条记录独立 nonce；
- AAD 绑定日期和行号；
- 把记录移动到其他日期或位置会解密失败。

## 恢复密钥与包

`.inkkey`：

- 用独立备份密码包裹 DEK；
- 加密携带仓库地址和分支；
- 不含 token、代理、正文、附件。

`.minidiary`：

- 整库 ZIP64；
- 公钥 + 私钥双因子包裹 DEK；
- 正文、批注、附件全部以密文形式保存。

`.inkatt`：

- 附件包；
- 使用独立的包密钥包裹 DEK；
- 只包含附件文件和加密清单。

## 内存与日志

- 解锁后密钥只在主进程内存中；
- 锁定、退出和切换库时清除密钥缓存；
- 渲染进程拿不到 DEK 或原始文件句柄；
- 日志不记录密码、密钥、正文和附件名。

## 边界

加密能保护磁盘上的数据，但不能防止：

- 已解锁电脑被他人直接操作；
- 操作系统或恶意软件在内存中窃取密钥；
- 弱密码被离线暴力尝试；
- 备份密钥文件与密码同时泄露。

密码无法找回；迁移包密码和 `.inkkey` 备份密码同样无法找回。
